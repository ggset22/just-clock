# Часы для Android (Kivy)

Простое приложение: цифровые часы на весь экран, настраиваемый фон
(цвет или своя картинка), настраиваемый цвет циферблата, включение/
выключение секунд.

## Файлы

- `main.py` — весь код приложения.
- `buildozer.spec` — конфиг для сборки APK.

## Как проверить на компьютере (без телефона)

Приложение написано на Kivy, поэтому его можно сразу запустить на
Windows/macOS/Linux, установив Kivy:

```bash
pip install kivy
python main.py
```

Так вы сразу увидите, как всё работает, ещё до сборки APK.

## Как собрать APK для Android

Собрать `.apk` можно только на **Linux** (нативно, через WSL2 на
Windows, или в Docker) — там разворачивается Android SDK/NDK.

1. Установите Buildozer:
   ```bash
   pip install buildozer cython
   ```
2. Установите системные зависимости Buildozer для вашего дистрибутива —
   список есть в официальной документации:
   https://buildozer.readthedocs.io/en/latest/installation.html
3. В папке проекта (там, где `main.py` и `buildozer.spec`) выполните:
   ```bash
   buildozer -v android debug
   ```
   Buildozer сам скачает Android SDK/NDK (первая сборка займёт
   значительное время) и создаст файл вида
   `bin/myclock-1.0-armeabi-v7a-debug.apk`.
4. Установите APK на телефон:
   ```bash
   buildozer android deploy run
   ```
   или просто скопируйте `.apk` на телефон и установите вручную
   (нужно разрешить установку из неизвестных источников).

### Если хотите собрать без своего Linux/WSL

Проще всего — открыть этот проект в GitHub Codespaces / любом
Linux-CI (например, GitHub Actions с готовым workflow для Buildozer)
и запустить там `buildozer android debug`.

## Как пользоваться приложением

- На главном экране — часы во весь экран.
- Значок ⚙ в правом верхнем углу открывает настройки.
- В настройках:
  - выбор цвета фона (или своей картинки — кнопка «Выбрать картинку
    фона»);
  - выбор цвета часов;
  - переключатель «Показывать секунды».
- Кнопка «Назад» возвращает на экран часов, настройки применяются
  сразу и сохраняются между запусками приложения.
